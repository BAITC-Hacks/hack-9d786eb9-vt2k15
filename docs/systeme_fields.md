# Поля Excel: Systeme electric

Полная инвентаризация шести исходных файлов и восьми листов (два листа скрыты). Excel прочитан без изменений и пересчёта. Точные исходные заголовки, адреса, типы, статистика заполнения, семейства формул, итоговые ячейки и SHA256 находятся в `systeme_fields.json`. Примеры результатов формул — сохранённый Excel-кэш, не новый расчёт.

«Исходное значение» означает литерал в файле, а не доказанный ручной ввод. Предлагаемые типы БД — рекомендации: коды/артикулы/номера документов хранить как TEXT, количества — как знаковый NUMERIC, даты текстового источника парсить отдельно. Пустые ячейки не приравнены к нулю.

## Ключи и связи

| Файл/таблица | Код 1С | Артикул | Гранулярность |
|---|---|---|---|
| MOQ | C | D | Один товар |
| Динамика продаж | D | нет | Строка документа/товар |
| Ежемесячные остатки | C | нет | Товар с 33 месячными колонками |
| Ежемесячные продажи | B | C | Товар с 33 месячными колонками |
| Товар в пути / TDSheet | C | B | Товар на дату снимка |
| Все Лист1 сезонности | нет | нет | Агрегат по году/месяцу, отдельные блоки |

Код 1С — кандидат для сопоставления товаров, но множества кодов различаются. Порядковый №, наименование и номер документа не являются первичным ключом строки товара. Для происхождения данных сохранять файл, лист, строку и дату импорта. Месячные колонки разумно развернуть в `(товар, месяц, показатель, значение)`, сохранив различие продаж и остатков. Не суммировать повторно одноимённые данные из рабочего снимка, месячной выгрузки и скрытых сводов.

## Выявленные особенности формата

- У динамики продаж XML `dimension` равен `H77314`, хотя фактическая область — `A1:H77314`. Парсер не должен использовать этот атрибут как единственный источник границ.
- В TDSheet `AQ485 = AP485/5` отличается от обычного делителя 12; `S485` и `T485` пусты. Основание исключения в файле не подписано.
- Проверка текущего снимка: `AX - AY = AZ` выполняется во всех 497 товарных строках; эти колонки при этом сохранены литералами.
